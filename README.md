# Student Portfolio Website

My personal portfolio website, made as the first practical of the Full Stack Development subject.

## About

A single page portfolio that shows my education, technical skills, projects, internship experience and contact details. The page is responsive, so it also works properly on mobile screens.

## Technology Used

- React (components, props, useState)
- Vite (for running and building the project)
- Plain CSS (no CSS framework)

## Sections

Home, About Me, Education, Skills, Projects, Internship, Contact, Footer

## Folder Structure

```
src/
  components/     all the section components
  data.js         all the content of the website
  index.css       all the styling
  App.jsx         puts all the sections together
  main.jsx        starting point of the app
```

## How to Run

Install the packages first:

```
npm install
```

Then start the development server:

```
npm run dev
```

Now open the link shown in the terminal (usually http://localhost:5173) in the browser.

To make the final build for deployment:

```
npm run build
```
